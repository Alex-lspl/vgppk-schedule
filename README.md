# Расписание ВГППК

Красивая версия страницы https://rasp.vgppk.ru/bg203.htm: сайт для браузера + JSON API, которое можно использовать в Android-приложении.

```
Сайт колледжа ──HTML──▶ /api/schedule (Vercel, кэш 10 мин) ──JSON──▶ веб-страница
                                                            └──JSON──▶ Android-приложение
```

Сайт колледжа не отдаёт данные в удобном виде, поэтому сервер на Vercel забирает HTML, разбирает его в JSON и кэширует ответ на 10 минут. Сколько бы человек ни открыло приложение, на сайт колледжа уходит максимум один запрос в 10 минут.

## Запуск

1. Создай репозиторий на GitHub и залей туда содержимое этой папки.
2. На https://vercel.com нажми **Add New → Project**, выбери репозиторий, ничего не меняя в настройках, нажми **Deploy**.
3. Открой выданный адрес вида `https://твой-проект.vercel.app`.

Локально: `npm i -g vercel`, затем `vercel dev`.

## Настройка (`public/app.js`, блок `CONFIG`)

| Параметр | Что делает |
|---|---|
| `defaultPage` | Группа по умолчанию (`bg203` = группа 841). Другую группу можно выбрать прямо в приложении. |
| `oddIsoWeekIs` | Какая неделя расписания (1 или 2) приходится на нечётные недели года. **Если показывается не та неделя — поменяй значение на 2.** |
| `TIMETABLE` | Звонки по дням недели (блок над `CONFIG`). Уже заполнены: понедельник отдельно, вторник–пятница одинаково, суббота без времени. Меняются в одном месте. |
| `refreshMs` | Период автообновления (по умолчанию 10 минут). |

## Подгруппы и ручные исправления

На сайте колледжа подгруппы не обозначены, а преподаватели по английскому перепутаны. Поэтому в `lib/fixes.js` лежит список ручных исправлений: они применяются на сервере после разбора страницы и попадают и на сайт, и в Android-приложение. Сейчас там для группы 841:

| Пара | Как на сайте колледжа | Как показывает приложение |
|---|---|---|
| Пн, 5 пара, Ин. язык | Яньшина Н.В., каб. 323 | 2 подгруппа, Рыжкова Н.И., каб. 355 |
| Вт, 1 пара, Ин. язык | Рыжкова Н.И., каб. 355 | 1 подгруппа, Яньшина Н.В., каб. 323 |

Кабинет переставляется вместе с преподавателем (у Яньшиной Н.В. всегда 323, у Рыжковой Н.И. всегда 355) — так на сайте они и закреплены, просто дни перепутаны.

Как это работает в интерфейсе: над расписанием появляется переключатель **Все / 1 подгр. / 2 подгр.** Выбор запоминается. В режиме «Все» у пар подгрупп есть метка, а в режиме «1 подгр.» или «2 подгр.» пары чужой подгруппы скрываются.

Как менять: открой `lib/fixes.js` на GitHub, отредактируй список (`day`: 0 = Пн … 6 = Вс, `pair` — номер пары как на сайте). Если колледж потом исправит расписание сам, оставь правило: оно просто задаёт те же значения. Если пару перенесут в другой день или на другой номер, правило перестанет срабатывать, и его нужно обновить или удалить.

## API

`GET /api/schedule?page=bg203`

```json
{
  "name": "841",
  "updated": "21.09.2026 18:23",
  "fetchedAt": "2026-09-21T15:30:00.000Z",
  "weeks": [
    {
      "number": 1,
      "days": [
        {
          "index": 0,
          "name": "Пн",
          "lessons": [
            { "pair": 1, "subject": "ГрафДизаин и Мультимедиа", "room": "132", "teacher": "Семичева А.Г.", "subgroup": null, "note": null }
          ]
        }
      ]
    }
  ]
}
```

- Параметр `t` — «ведро времени» против устаревшего кэша. Сервер держит ответ 10 минут, а если запросить с новым `t`, он заберёт свежую страницу. Веб-версия передаёт `t = floor(now / 10 минут)` при автообновлении и `t = floor(now / 1 минуту) + "m"` при нажатии «Обновить». Так на сайт колледжа уходит не больше одного запроса в минуту, сколько бы людей ни жало кнопку.
- Поля `updated` (когда обновили расписание на сайте колледжа) и `fetchedAt` (когда сервер его забрал) удобно показывать пользователю.
- `days` всегда содержит 7 элементов (Пн–Вс); пустой день — пустой массив `lessons`.
- `subgroup` — номер подгруппы (1 или 2) либо `null`, если пара для всей группы. Две записи с одинаковым `pair` в один день — тоже подгруппы.
- `GET /api/groups` → `{ "groups": [ { "page": "bg203", "name": "841" } ] }`.
- Ошибка: HTTP 502 и `{ "error": "..." }`.

## Если что-то не работает

- **502 и «Сайт колледжа ответил 403» или таймаут.** Некоторые российские сайты блокируют зарубежные IP, а серверы Vercel находятся за рубежом (в `vercel.json` выбран Франкфурт как ближайший к России). В этом случае парсинг придётся делать на самом телефоне (см. вариант Б ниже) или на сервере в России.
- **«Не удалось найти расписание на странице».** Изменилась вёрстка сайта. Открой страницу, скопируй HTML (Ctrl+U) и поправь `lib/parse.js`. Парсер опирается на ссылки `j…`, `ba…`, `bp…` и тексты «Пн», «Неделя 1», «Обновлено:».
- **Замены.** Приложение показывает только основное расписание — замены колледж на сайте не публикует, только на бумажных листочках, поэтому автоматически их показать нельзя.

Тесты парсера: `npm test`.

# Android-приложение

## Вариант А: оболочка над сайтом (15 минут)

Приложение просто открывает твой сайт из Vercel в WebView. Дизайн и логика обновляются деплоем на Vercel, без переиздания приложения.

1. Android Studio → **New Project → Empty Views Activity** (Kotlin).
2. `AndroidManifest.xml`, перед `<application>`:
   ```xml
   <uses-permission android:name="android.permission.INTERNET" />
   ```
3. `MainActivity.kt`:
   ```kotlin
   import android.os.Bundle
   import android.webkit.WebView
   import android.webkit.WebViewClient
   import androidx.activity.OnBackPressedCallback
   import androidx.appcompat.app.AppCompatActivity

   class MainActivity : AppCompatActivity() {
       override fun onCreate(savedInstanceState: Bundle?) {
           super.onCreate(savedInstanceState)
           val web = WebView(this).apply {
               settings.javaScriptEnabled = true
               settings.domStorageEnabled = true   // нужно для кэша расписания
               webViewClient = WebViewClient()
               loadUrl("https://ТВОЙ-ПРОЕКТ.vercel.app")
           }
           setContentView(web)
           onBackPressedDispatcher.addCallback(this, object : OnBackPressedCallback(true) {
               override fun handleOnBackPressed() {
                   if (web.canGoBack()) web.goBack() else finish()
               }
           })
       }
   }
   ```

Минус: без интернета первая загрузка страницы не откроется (сохранённое расписание работает, только если страница уже была загружена в этой сессии).

## Вариант Б: нативное приложение (Jetpack Compose)

Полноценное приложение с виджетом и уведомлениями, работает офлайн. Дай Gemini в Android Studio такой запрос:

> Создай Android-приложение на Kotlin + Jetpack Compose (Material 3) «Расписание колледжа».
>
> **Данные.** GET `https://ТВОЙ-ПРОЕКТ.vercel.app/api/schedule?page=bg203` возвращает JSON:
> `{ name: String, updated: String?, weeks: [ { number: Int, days: [ { index: Int, name: String, lessons: [ { pair: Int, subject: String, room: String?, teacher: String?, note: String? } ] } ] } ] }`.
> `days` — 7 элементов (Пн–Вс). Одинаковый `pair` в один день — подгруппы.
> GET `/api/groups` возвращает `{ groups: [ { page: String, name: String } ] }`.
>
> **Требования.**
> 1. Retrofit + kotlinx.serialization (или Moshi), ViewModel, StateFlow.
> 2. Экран расписания: сверху название группы (по нажатию — выбор группы из `/api/groups`, выбор хранить в DataStore), переключатель «Неделя 1 / Неделя 2», полоса дней Пн–Сб с датами. Ниже список пар выбранного дня: номер пары, предмет, преподаватель, крупно номер аудитории. Между парами с пропуском номера — плашка «Окно».
> 2a. У пары может быть поле subgroup (1, 2 или null). Над списком пар сделай переключатель «Все / 1 подгр. / 2 подгр.» (показывать, только если в данных есть хотя бы одна подгруппа), выбор хранить в DataStore. В режиме «Все» показывать у пары метку «N подгруппа», в остальных режимах скрывать пары другой подгруппы (пары с subgroup = null показывать всегда).
> 3. По умолчанию открывать сегодняшний день; текущую неделю определять по чётности недели года с настраиваемым смещением.
> 4. Кэшировать последний ответ в Room или DataStore и показывать его при отсутствии сети с пометкой.
> 5. Автообновление каждые 10 минут, пока приложение открыто. К запросу добавляй параметр `t` = `System.currentTimeMillis() / 600000`.
> 6. Под заголовком всегда показывать строку «Расписание на сайте колледжа обновлено: {updated}» и «Приложение проверило сайт в {время последней успешной загрузки}». Рядом кнопка «Обновить» (плюс pull-to-refresh): она делает запрос с `t` = `"${System.currentTimeMillis() / 60000}m"`, чтобы обойти кэш сервера.
> 7. Звонки: понедельник — слоты 1: 08:30–10:05, 2: 10:15–11:50, 3 (кураторский час): 12:00–12:45, 4: 13:30–15:05, 5: 15:15–16:50; вторник–пятница — 1: 08:30–10:05, 2: 10:15–11:50, 3: 12:30–14:05, 4: 14:15–15:50; суббота без времени. Показывать время под номером пары и подсвечивать идущую сейчас пару.
> 8. Тёмная и светлая темы, обработка состояний загрузки и ошибок.

Если Vercel окажется заблокирован сайтом колледжа (см. «Если что-то не работает»), попроси Gemini вместо Retrofit-запроса к API скачивать `https://rasp.vgppk.ru/bg203.htm` напрямую и разбирать библиотекой Jsoup по тем же правилам, что в `lib/parse.js`: ссылки `j…` — предмет, `ba…` — аудитория, `bp…` — преподаватель, тексты «Пн», «1», «Неделя 2» — день, пара, неделя.
