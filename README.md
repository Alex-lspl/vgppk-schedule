# Расписание ВГППК

Альтернативный вид страницы https://rasp.vgppk.ru/bg203.htm: то же самое расписание, но удобно читать с телефона и компьютера.

```text
Сайт колледжа ──HTML──▶ /api/schedule (Vercel, кэш) ──JSON──▶ веб-страница
```

Сайт колледжа не отдаёт данные в удобном виде, поэтому сервер на Vercel забирает HTML, разбирает его в JSON и кэширует ответ. Сколько бы человек ни открыло страницу, сайт колледжа при этом опрашивается редко (см. «Как часто опрашивается сайт колледжа» ниже).

## Возможности

- Расписание на неделю с переключением «Неделя 1 / Неделя 2» и днями недели с датами.
- Подгруппы: переключатель «Все / 1 подгр. / 2 подгр.», выбор запоминается.
- Звонки под номером пары, подсветка идущей сейчас пары и обеденного перерыва.
- Работает без интернета по последним сохранённым данным (кэш в браузере).
- Тёмная тема, адаптивная вёрстка от маленьких телефонов до широких мониторов.
- Показывает, когда колледж в последний раз менял расписание на сайте и когда это в последний раз проверяло само приложение (иконка ⓘ рядом со статусом — с пояснением).
- Админка на `/admin` (под логином/паролем) — вручную поправить расписание на текущую неделю, если прислали замену; правка сама сбрасывается к понедельнику.
- Свою иконку можно добавить на экран «Домой» на телефоне (см. ниже) — откроется как отдельное приложение, без адресной строки браузера.

## Запуск

1. Создай репозиторий на GitHub и залей туда содержимое этой папки.
2. На https://vercel.com нажми **Add New → Project**, выбери репозиторий, ничего не меняя в настройках, нажми **Deploy**.
3. Открой выданный адрес вида `https://твой-проект.vercel.app`.

Локально: `npm i -g vercel`, затем `vercel dev`.

## Настройка (`public/app.js`, блок `CONFIG`)

| Параметр | Что делает |
|---|---|
| `defaultPage` | Страница группы по умолчанию (`bg203`). В документации отображаемый номер группы — `042`. Другую группу можно выбрать прямо на странице. |
| `oddIsoWeekIs` | Какая неделя расписания (1 или 2) приходится на нечётные недели года. **Если показывается не та неделя — поменяй значение на противоположное.** |
| `TIMETABLE` | Звонки по дням недели (блок над `CONFIG`). Уже заполнены: понедельник отдельно, вторник–пятница одинаково, суббота без времени. |
| `peakStartHourMsk` / `peakEndHourMsk` / `peakRefreshMs` / `offPeakRefreshMs` | Как часто сама страница проверяет сайт колледжа — см. следующий раздел. |

## Подгруппы и ручные исправления

Сайт колледжа не подписывает, где какая подгруппа — только объединяет пары. Поэтому в `lib/fixes.js` лежит список ручных подсказок: они применяются на сервере после разбора страницы. В примерах ниже используется группа `042` и явно тестовые обозначения преподавателей.

| Пара | На сайте | Подгруппа |
|---|---|---|
| Пн, 5 пара, Ин. язык | ТЕСТОВЫЙ ПРЕПОДАВАТЕЛЬ 1, каб. 323 | 1 подгруппа |
| Вт, 1 пара, Ин. язык | ТЕСТОВЫЙ ПРЕПОДАВАТЕЛЬ 2, каб. 355 | 2 подгруппа |

Как это работает в интерфейсе: над расписанием появляется переключатель **Все / 1 подгр. / 2 подгр.** Выбор запоминается. В режиме «Все» у пар с подгруппой есть метка, а в режиме «1 подгр.» или «2 подгр.» пары чужой подгруппы скрываются.

Как менять: открой `lib/fixes.js` на GitHub, отредактируй список (`day`: 0 = Пн … 6 = Вс, `pair` — номер пары как на сайте, `set` — какие поля перезаписать: `subgroup`, `teacher`, `room`, `subject`, `note`). Если пару перенесут на другой день или другой номер, правило перестанет срабатывать, и его нужно будет обновить.

## Как часто опрашивается сайт колледжа

Чтобы не дёргать сайт колледжа без необходимости, частота проверки зависит от московского времени (см. `lib/refreshWindow.js`):

- **6:00–17:00 МСК** (учебные часы) — раз в 30 минут.
- **В остальное время** — раз в 2 часа.

Это ограничение — на уровне кэша сервера (Vercel), поэтому оно действует независимо от того, сколько человек одновременно открыло страницу и как часто каждый из них жмёт «Обновить»: сайт колледжа физически не может быть опрошен чаще, чем раз в 30 минут (или 2 часа ночью), даже если открыть страницу сто раз подряд. Кнопка «Обновить» на странице обходит только собственный кэш браузера, а не это ограничение.

## Админка (ручные замены на неделю)

На `/admin` есть страница, где можно вручную отредактировать расписание на **текущую календарную неделю** — например, если прислали замену. Как только наступает следующий понедельник, правка перестаёт действовать сама по себе, и расписание возвращается к тому, что на сайте колледжа — ничего удалять руками не нужно.

После входа сессия держится 30 дней (кука в браузере), так что логиниться каждый раз не придётся. Кнопка «Выйти» в правом верхнем углу панели сбрасывает сессию.

Если захочешь сменить логин/пароль — открой `lib/adminAuth.js` на GitHub и поменяй `ADMIN_USER`/`ADMIN_PASS`. Там же лежит `SESSION_SECRET` — если его поменять, все, кто уже вошёл, будут разлогинены.

### Как это хранится

Правки лежат в обычном JSON-файле `data/overrides.json` прямо в этом репозитории — **не в отдельной базе данных**. Когда ты сохраняешь изменения в админке, она коммитит обновлённый файл в репозиторий через GitHub API (это и есть «сохранение» — можно открыть файл на GitHub и увидеть историю правок по коммитам). Сайт при каждом запросе просто читает текущее содержимое этого файла.

Раз это коммит в репозиторий, Vercel увидит новый пуш и пересоберёт сайт (меньше минуты, без простоя) — для правки раз в неделю это не проблема, это нормально.

### Настройка (один раз)

1. **Создай токен доступа GitHub**: GitHub → фото профиля → **Settings** → **Developer settings** (в самом низу слева) → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
   - **Repository access**: Only select repositories → выбери этот репозиторий.
   - **Permissions → Repository permissions → Contents** → выбери **Read and write**.
   - Нажми **Generate token** и скопируй его (больше он нигде не покажется).
2. В Vercel: открой свой проект → **Settings** → **Environment Variables**, добавь:
   - `GITHUB_TOKEN` — токен из шага 1
   - `GITHUB_REPO` — `username/repository` (заглушка вместо реального GitHub-логина и названия репозитория).
3. **Redeploy**: Vercel → вкладка **Deployments** → у последнего деплоя ⋯ → **Redeploy** (новые переменные окружения применяются только после пересборки).
4. Открой `https://твой-проект.vercel.app/admin`, введи настроенные логин и пароль администратора.

Без этих переменных страница `/admin` по-прежнему открывается (после логина), но сохранить ничего не получится — наверху будет понятное предупреждение об этом.

### Как пользоваться

- Выбери группу, разверни нужный день, поставь галочку «переопределить этот день» — после этого можно менять поля (предмет/преподаватель/кабинет/подгруппа/заметка) и добавлять/удалять пары кнопками.
- День без галочки не трогается — показывается то, что реально на сайте колледжа.
- **Сохранить** — записывает изменения (коммит в GitHub).
- **Сбросить всю неделю** — убирает все правки для выбранной группы, возвращает всё к дефолту.
- Студенты увидят изменения на сайте в течение получаса (кэш, см. раздел ниже) либо сразу, если нажмут кнопку «Обновить» на странице — она кэш обходит.

## API

`GET /api/schedule?page=bg203`

```json
{
  "name": "042",
  "updated": "21.09.2026 18:23",
  "fetchedAt": "2026-09-21T15:30:00.000Z",
  "weeks": [
    {
      "number": 1,
      "days": [
        {
          "index": 0,
          "name": "Пн",
          "lessons": [
            {
              "pair": 1,
              "subject": "ГрафДизаин и Мультимедиа",
              "room": "132",
              "teacher": "ТЕСТОВЫЙ ПРЕПОДАВАТЕЛЬ 3",
              "subgroup": null,
              "note": null
            }
          ]
        }
      ]
    }
  ]
}
```

- `updated` — когда колледж в последний раз менял расписание на своём сайте; `fetchedAt` — когда сервер последний раз его забирал.
- `days` всегда содержит 7 элементов (Пн–Вс); пустой день — пустой массив `lessons`.
- `subgroup` — номер подгруппы (1 или 2) либо `null`, если пара для всей группы. Две записи с одинаковым `pair` в один день — тоже подгруппы.
- `weekKey` — календарная неделя по МСК (например, `"2026-W39"`), `liveWeekNumber` — какая из веток (`1` или `2`) сейчас актуальна.
- `hasAdminOverrides: true` появляется, только если на эту неделю есть правки из админки.
- `GET /api/groups` → `{ "groups": [ { "page": "bg203", "name": "042" } ] }`.
- Ошибка: HTTP 502 и `{ "error": "..." }`.

## Если что-то не работает

- **502 и «Сайт колледжа ответил 403» или таймаут.** Некоторые российские сайты блокируют зарубежные IP, а серверы Vercel находятся за рубежом (в `vercel.json` выбран Франкфурт как ближайший к России). Такое может встретиться на некоторых хостингах или в некоторых регионах.
- **«Не удалось найти расписание на странице».** Изменилась вёрстка сайта. Открой страницу, скопируй HTML (Ctrl+U) и поправь `lib/parse.js`. Парсер опирается на ссылки `j…`, `ba…`, `bp…` и тексты «Пн», «Неделя 1», «Обновлено:», а название группы берёт из `<h1>` с двоеточием (на странице их два: один — название сайта, второй — «Группа: …»).
- **Замены.** Сайт колледжа их не публикует (только на бумажных листочках) — автоматически их подтянуть нельзя. Для этого есть админка, см. раздел выше.
- **В админке баннер «GitHub не настроен».** Не заданы `GITHUB_TOKEN`/`GITHUB_REPO` в Vercel, либо после их добавления не сделан **Redeploy** — новые переменные окружения применяются только к следующей сборке.
- **«GitHub ответил 401/404 при сохранении».** 401 — токен неверный или просрочен (сделай новый). 404 — неправильно указан `GITHUB_REPO` (должно быть ровно `логин/репозиторий`) или у токена нет доступа к этому репозиторию.
- **«GitHub ответил 403...rate limit».** Такое бывает только при очень частых сохранениях подряд — для правки раз в неделю это практически невозможно.
- **Браузер не показывает окно входа на `/admin`.** Если уже когда-то вводил логин/пароль (даже неверный) — браузер мог запомнить его на этот сайт. Открой `/admin` в режиме инкогнито, чтобы проверить начисто.

Тесты парсера: `npm test`.
